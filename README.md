# process-tracker

Mini motor de tramitação de processos municipais (alvará de obra, licença sanitária e autorização de evento) em Java 17 + Spring Boot 4.

Projeto de estudo para praticar POO, polimorfismo, generics, SOLID, IoC/proxies AOP do Spring e padrões de projeto (Strategy, Provider/SPI, eventos).

## Stack

- Java 17
- Spring Boot 4.1
- Lombok
- JUnit 5, AssertJ e Mockito

## Como executar

Pré-requisito: JDK 17 ou superior. O Maven Wrapper baixa o Maven na primeira execução.

```bash
./mvnw test
```
